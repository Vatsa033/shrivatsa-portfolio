04 / Projects · Systems Engineering

Aircraft Maintenance
& BITE Fault Analytics.

A systems-oriented data project connecting fault detection, BITE information, maintenance events and aircraft-system context into one analytical workflow.

01 / System objective

From fault event
to maintenance insight.

PROBLEM

Aircraft maintenance data can become fragmented across sensor events, fault codes, BITE outputs, component records and maintenance actions, making recurring failures and system-level trends difficult to see.

APPROACH

Created a simulated aerospace maintenance-data environment using public sensor data and synthetically generated BITE and maintenance records.

DATA PIPELINE

Built a Python workflow to clean, transform and structure sensor and maintenance-event data before analysis.

SYSTEM MODEL

Designed a PostgreSQL relational structure around aircraft, systems, components, fault codes, BITE events and maintenance actions.

ANALYTICS

Developed fault-frequency, recurring-failure, downtime and Mean Time Between Failures (MTBF) analytics.

INTERFACE

Built an interactive Streamlit dashboard with Plotly visualizations for filtering faults by aircraft, system, component and fault code.

02 / Systems flow
FAULT DETECTION→BITE EVENT→DATA STORAGE→FAULT ANALYSIS→MAINTENANCE INSIGHT
03 / What I built

Connecting the
layers.

The project was structured as a small systems pipeline rather than a standalone dashboard: the data model represents relationships between aircraft, systems and components; the processing layer transforms raw events; the analytics layer identifies patterns; and the dashboard exposes those patterns for investigation.
