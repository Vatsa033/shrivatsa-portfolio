01 · Project context

What the VSM is trying to improve

The value stream is the small-parts replenishment path feeding the soft machining line. The project reframes replenishment as a controlled system rather than an operator-driven transport activity.

Why change?

The current flow relies on walking, workstation waiting and manual handling. The future state shifts replenishment toward a predictable pull-based milk-run with ergonomic point-of-use supply.

Project logic

1Map the current flow
2Expose the waste
3Standardize replenishment
4Protect the operator

05 · Lean intervention

Replace variability with a standard flow.

The intervention combines inventory discipline, a pull trigger, scheduled transport and ergonomic point-of-use supply. The point is not automation for its own sake; it is to make replenishment repeatable.

FIFO

First-in-first-out

Keeps inventory handling structured and visible.

PULL / KANBAN

Demand-triggered supply

Replenishment is triggered by actual use rather than ad-hoc requests.

AGV MILK-RUN

3 min route · every 15 min

A standardized transport loop replaces repeated walking.

JIDOKA + RACK

Point-of-use supply

Ergonomic rack logic supports error-proof, accessible material presentation.
